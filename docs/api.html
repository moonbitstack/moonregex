    The core engine speaks one grammar, so this answers only for the patterns that fit inside it: literals, classes, ., ^, $, \b, \B, groups, alternation, quantifiers up to 256.   • escape(StringView, dialect? : @parse.Dialect, special_only? : Bool, literal_spaces? : Bool) -> String

    Escape pattern so the result matches it literally, under dialect.

    The three grammars do not agree on what needs escaping, so the same string comes back spelled three ways:

    - Python — Python's re.escape: the characters that can mean something to the grammar are backslashed, everything else is left alone. With special_only off every non-alphanumeric is escaped; literal_spaces stops spaces from being escaped. - Ecma262 — RegExp.escape of ECMA-262: punctuation that is not a syntax character becomes \x.., syntax characters are backslashed, and a leading alphanumeric is spelled \x.. too so the result can never read as a quantifier's neighbour. - Lexmatch — the @string.Regex grammar: its metacharacters are backslashed and control characters are spelled in the escapes that grammar knows (\n, \t, \u{..}), never \x...

Flags

The switches a pattern can carry.

A record rather than a bitmask, because every one of these is a thing a reader may want to look at, set, or refuse — (?a) inside a scoped group changes what \w means for that group alone, and a bitmask cannot be asked about politely.

Flags are resolved into the syntax tree at parse time: (?s:.) puts the dotall behaviour inside the node, so the executor never consults them.

  • new(ignorecase? : Bool, multiline? : Bool, dotall? : Bool, verbose? : Bool, ascii? : Bool, unicode? : Bool, unicode_set…

    Build flags, leaving unset switches at their preset.

    A flag that is only meaningful in one dialect is accepted everywhere and refused by the parser when the grammar cannot honour it — verbose under ECMA-262, for instance — so that the mistake is named where it happens.

Node

One node of the syntax tree every dialect is lowered into.

The tree is resolved: flags have been folded into the nodes that care ((?s:.) is an Any that eats newlines, (?i)k is a class holding both cases), so the executor never asks which grammar a node came from.

  • shift_slots(Self, Int32) -> Self

    The tree with every capture slot moved up by by.

    Composing two patterns renumbers the right-hand one's groups so the result is numbered as one written pattern would be — the left operand keeps 1..n, the right one continues at n+1.

CharSet

A set of code points, kept as sorted disjoint inclusive ranges.

Character classes, \p{...}, \w and the rest are all this one shape, so the set algebra a pattern needs — union for [a-z], difference for --, intersection for &&, complement for [^…] — lives here once.

  • any() -> Self

    Every code point, surrogates included.

  • complement(Self) -> Self

    Complement over every code point: what [^…] means.

  • contains(Self, Int32) -> Bool

    Whether a code point is in the set.

  • difference(Self, Self) -> Self

    Difference: the V1 set algebra's --.

  • empty() -> Self

    The empty set.

  • fold(Self) -> Self

    Close the set under simple case folding: add the folded form of everything in it, and the unfolded form of everything that folds into it.

    This is what (?i) does to a class at parse time: fold the pattern, not the input, so the executor stays a plain membership test. Only single code point folds exist here, so ß does not grow an ss — matching it against SS is out of scope, exactly as it is in Python's re.

  • intersection(Self, Self) -> Self

    Intersection: the V1 set algebra's &&.

  • is_empty(Self) -> Bool

    Whether the set holds nothing.

  • of(Array[(Int32, Int32)]) -> Self

    Build a set from ranges, sorting and merging them first.

    The input may be in any order and may overlap; the stored form is always sorted, disjoint and coalesced, which is what makes contains a binary search and the algebra linear.

  • ranges(Self) -> Array[(Int32, Int32)]

  • symmetric_difference(Self, Self) -> Self

    Symmetric difference: the V1 set algebra's ~~.

  • union(Self, Self) -> Self

    Union: [a-z] or, in the V1 set algebra, ||.
