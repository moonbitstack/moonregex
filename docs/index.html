what it does

One engine, many dialects.

A pattern is read by the grammar it was written in, lowered into one tree, and run by one backtracking machine — so switching grammars does not mean rewriting patterns.

01

Three grammars

Python's re, ECMA-262, and the lexmatch grammar the core library speaks. Named groups read as (?P<n>…), (?<n>…) and (?'n'…).

python · ecma262 · lexmatch
02

The hard parts

Backreferences, variable-length lookbehind, conditionals, recursion, atomic groups and possessive quantifiers — read, lowered, and executed.

(?(1)x|y) · (?>…) · (?R)
03

Fuzzy matching

A bounded edit budget over a literal run: {e<=1}, {i<=1}, {d<=1}, {s<=1}, and the weighted form. The spent budget is reported on the match.

approximate search
04

Shell globs

fnmatch, Glob and GlobSet translate *, **, ?, […] and {a,b} into patterns, with path-aware matching.

fnmatch · Glob · GlobSet
05

Unicode, from the UCD

\p{…} takes a category, script, block or binary property; \X matches one grapheme cluster; offsets count characters, not bytes. The tables come from moonucd.

\p{Script=Han} · \X
06

Next to the core engine

A pattern the core engine can run lowers onto it as a @string.Regex; the combinators are the same five; a match carries both views.

lower() · string · + · | · repeat
