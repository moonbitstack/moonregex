what it does

One engine, many dialects.

A single parse tree lowers into three grammars and one backtracking virtual machine. Reach for what the job needs — and switch without rewriting your patterns.

01

Three dialects

Python re, ECMA-262 and Lexmatch share one tree. Named groups read as (?P<n>), (?<n>) and (?'n').

python · ecma262 · lexmatch
02

Deep syntax

Backreferences, look-ahead and look-behind, conditionals, atomic groups, recursion and possessive quantifiers — the hard parts, handled.

(?(1)x|y) · (?>…) · (?R)
03

Fuzzy matching

A bounded Levenshtein budget over literal runs: {e<=1}, {i<=1}, {d<=1}, {s<=1} — insertions, deletions and substitutions.

approximate search
04

Shell globs

The glob package translates *, **, ?, […] and {a,b} into patterns, with path-aware matching.

fnmatch · Glob · GlobSet
05

Unicode, properly

Codepoint classes, \p{…} properties, case- and line-aware flags, and correct counting of characters, not bytes.

\p{Script=Han}
06

Four targets

One source, four backends: native, wasm, wasm-gc and js. The same test suite runs green on all of them.

native · wasm · wasm-gc · js
in practice
